Hướng dẫn chi tiết

Không kết nối được VPS
  1. Kiểm tra lại IP, tên đăng nhập và mật khẩu.
  2. Đảm bảo điện thoại hoặc máy tính vẫn có Internet.
  3. Tắt Remote Desktop rồi mở và kết nối lại.
  4. Nếu vẫn lỗi, chụp nguyên màn hình báo lỗi và gửi Zalo.
VPS bị lag hoặc đầy RAM
  1. Đóng tab trình duyệt và phần mềm không sử dụng.
  2. Giảm số tài khoản game đang treo.
  3. Khởi động lại VPS rồi chờ 2–3 phút.
  4. Nếu thường xuyên đầy RAM, cân nhắc nâng gói.
Game hoặc file JAR không mở
  1. Đóng hẳn game trong Task Manager.
  2. Mở lại đúng file game đã được cài sẵn.
  3. Không tự xóa hoặc di chuyển thư mục Java/game.
  4. Gửi ảnh lỗi qua Zalo nếu vẫn không mở được.
Bị mất kết nối khi đang treo
  1. Kết nối lại Remote Desktop; mất màn hình không đồng nghĩa VPS đã tắt.
  2. Kiểm tra game còn chạy hay không.
  3. Nếu VPS vừa khởi động lại, chờ 2–3 phút rồi vào lại.
Cách khởi động lại VPS
  1. Mở Start trên VPS.
  2. Chọn biểu tượng nguồn rồi chọn Restart.
  3. Chờ 2–3 phút trước khi kết nối lại.
